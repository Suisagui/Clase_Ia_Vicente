# Ejercicios de Pandas con Iris

En esta carpeta están los ejercicios de la clase sobre selección, filtros, agrupación y limpieza de datos con Pandas.

Las soluciones y sus resultados están en [02_Ejercicios_Iris.ipynb](02_Ejercicios_Iris.ipynb).

## Archivos

- `iris_con_faltantes.csv`: datos para resolver los ejercicios.
- `iris_original.csv`: versión completa para comparar.
- `iris_procesado.csv`: archivo generado en el ejercicio 7.
- `01_Demostracion_Pinguinos.ipynb`: ejemplo de la clase.

## Cómo abrirlo

Abre el cuaderno de Iris en Jupyter o en VS Code y ejecuta las celdas en orden. Deja los CSV en la misma carpeta para que el programa los encuentre.

Si faltan Pandas o el kernel de Python, puedes instalarlos desde la terminal:

```bash
python -m pip install pandas ipykernel
```

Para ejecutar el ejemplo de pingüinos hace falta `penguins_size.csv`. El enlace para descargarlo está en ese cuaderno.
